# npm 0.9.0 release preparation and security qualification

This candidate prepares all ten npm packages for 0.9.0. Publication remains on hold pending explicit approval. The changelog stays Unreleased. No release tag, npm dist-tag change, npm publish, NuGet publish or release announcement is part of this preparation. NuGet preview.2 was already prepared separately on main; this change does not modify its package versions or source.

## Scope and dependency evidence

The base is main `15b3d523ca5e6efe08e1197d19d41cf7bfaec4c0`. All ten npm manifests and internal pins already used 0.9.0. The release notes were checked against the public API and the commit range since v0.8.3, including prose migration, HTTP rejection retry, tool-step display, native subagents, pending-browser recovery and OpenAI/Azure code execution. Previously recorded local-model limits remain explicit; deterministic contracts do not establish new hardware/model qualification.

The follow-redirects 1.16.1 → 1.16.2 lock change incorporates the patch proposed in PR #859 for GHSA-mrwp-f3q8-3g9p. Its original CI blocker was reproduced unchanged: the bootstrap test read deployment targets from pr-main after the catalog moved into select-deployment-targets. The fix reads the owning workflow and preserves the exact catalog and lifecycle/marketing assertions.

Expanded security qualification was explicitly approved after the inherited high-severity Zod advisory GHSA-mrhx-c7xc-m3w5 was found. AG-UI client/core/encoder/proto now resolve to 1.0.4. Direct published-package pins and root overrides align the family, including existing B4 dependencies, without changing B4 versions. AG-UI 1.0.4 removes hard Zod 3 dependencies from client/encoder/proto and accepts Zod 4 through its peer contract. The workspace resolves runtime Zod 4.6.7; the advisory's patched boundary is 4.6.6.

The existing Vercel development CLI advances from 59.26.0 to 65.12.1. This is **partial development-tool remediation**: the full workspace audit still reports 84 findings (2 low, 75 moderate, 7 high, 0 critical). Four nested Zod 3 installations remain under Vercel backends/express/hono/python-analysis; six high propagated package findings accompany the Zod advisory. npm's proposed Vercel 65.2.0 change is a downgrade, not a demonstrated safe fix. No incompatible Zod-major override or audit-fix-force was applied. The production-only workspace audit reports zero advisories; that result does not erase development-tool findings or guarantee every host application's peer choices.
