# .NET NuGet Packaging Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce `Hashbrown.AspNetCore` `0.1.0-preview.1` and qualify the actual packed artifact through isolated application consumers, unchanged deterministic conformance, documentation compilation and real source-to-package durable upgrades.

**Architecture:** Move the reusable integration into one `net10.0` library; keep the executable and application fixtures separate. One owned external PackageReference consumer, fresh candidate cache and immutable provenance descriptor supply every acceptance process/restart. Reuse existing scenario bodies and published npm consumer assets; do not fork a second framework implementation or duplicate the full browser run.

**Tech Stack:** .NET SDK 10.0.402, ASP.NET Core framework reference, the nine existing approved-version NuGet dependencies, Nx run-commands, Node built-ins, existing Jest/Playwright/aimock, PostgreSQL 18.
