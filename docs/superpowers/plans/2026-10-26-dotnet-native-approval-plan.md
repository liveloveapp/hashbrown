# Native .NET MAF approvals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resume genuine native MAF approval requests through unchanged published Hashbrown generic controls while retaining durable at-most-one dispatch and zero-dispatch decline/cancel semantics.

**Architecture:** Extend the existing native journal to schema 2 with permanent batch/decision fences and exact original request/browser-bypass bindings. A focused outer public `DelegatingAIAgent` bridges admitted decisions and projected echoes; MAF owns actual binding/invocation/history. Keep the original public request and supply browser declarations through cloned native options while only the AGUI transport clone uses empty tools.

**Tech Stack:** Existing pinned .NET 10, MAF 1.26.0 and AGUI.Server 1.0.1, Microsoft.Extensions.AI, Npgsql/PostgreSQL, Nx/Jest/Playwright, published React/Angular 0.8.3. No new dependencies/version changes.
