## Shared teaching contract

All three clients use actual text chat SDKs (`useChat` / `chatResource`) and capture actual SDK messages/lifecycle. Parser and forms feed the current assistant's raw JSON to the framework's real `useJsonParser` / `jsonParser`; no browser timer fabricates model tokens. The server constrains OpenAI output to a shared Skillet plan schema (ordinary title, streaming array of streaming step strings). Source completion, parser completion, final JSON/schema validation, application rules and explicit application actions remain distinct. Reparse the original complete JSON to catch omitted/withheld invalid members. Error hides stale previews; stopped partials remain labelled stopped, never successful.

Parser shows two actual generations, partial strings, validated document and inert replay. It never changes application state. Forms keeps generated draft, editable reviewed values and applied plan separate. Review copies a fresh successful complete draft into labelled editable fields. Apply revalidates trimmed title (1–120 characters) and exactly two nonempty steps (1–200 each), requires original valid document/current successful SDK finish, matching turn and application revision, and applies once. A new generation invalidates old review while preserving accepted data. A read-only browser readContext tool sends the actual applied plan/revision to each forms generation; edits and renders do not generate or submit. No server write/authorization implied.

Agent decisions classifies current bounded user text on the server with real TypeSafe, then runs one of application-owned read-only outline/record handlers over the same fixed plan, or clarifies. Use a closed route schema, decode envelope and finite confidence >=0.75. Invalid/low/unavailable operational decisions clarify; unexpected errors propagate as run errors; cancellation suppresses late output. A custom AG-UI trace captures safe actual decision value/meta and the selected handler/fallback. Handler text arrives whole; do not call it streamed model prose. The decision never supplies executable handlers or changes application state. Credentials/model versions remain server-only.

## Architecture

Extend history-format capture with optional typed authoring/parser/review and agent observations. Dedicated immutable store methods capture these without inventing SDK flags; replay cannot call SDK/parser mutation/providers/tools or write state. New application Apply method validates request origin, finish, document and reviewed plan before updating the existing application revision. Source identity checks reject old assistant observations during new sends, conversation switches, stop or teardown.

Shared helpers own schemas, bounded validation, source classification, guarded review/edit/apply and inspector projections. Framework clients own real SDK and parser hooks/resources. Agent routing is a narrow server stream wrapper around the existing workflow/OpenAI delegate; both normal host and verifier use it. Existing lessons, APIs and legacy assets remain. Catalog becomes 24 lessons/48 framework paths. Inspectors focus Agent, Parser or Form, with request/SDK/raw/state views retained.
