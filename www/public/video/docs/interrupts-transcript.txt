Pause for approval. Resume together.

Recorded from www/examples/quickstart/react/src/Workflows.tsx, with the same interactions verified in Angular. The real client runtime consumes scripted AG-UI responses. Presentation styles and a branded frame are added by the recorder. No narration.

1. The opening frame shows the approved result.
2. Select Plan a trip. The scripted agent returns two interrupts: approve the itinerary and confirm Lisbon.
3. The application displays both questions in one pending batch. No automatic continuation runs while answers are pending.
4. Select Approve and resume. The client submits a resolved response for each interrupt.
5. The agent accepts the run and replies: Approved. Your Lisbon itinerary is ready.

The endpoint fixture implements AG-UI interrupt outcomes and resume input. It is not a booking service and performs no purchase. An ordinary direct-provider endpoint does not create this workflow by itself.
