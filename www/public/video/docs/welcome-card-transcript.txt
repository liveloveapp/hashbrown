Generate your first welcome card

This recording uses the actual React Quickstart component, exposed component schema, and useUiChat hook in www/examples/quickstart/react. The same loading, rendering, and error-recovery interactions are verified against the Angular example before sharing the recording across both guides. Presentation styles and a branded frame are added by the recorder.

1. The opening frame shows the completed result: a WelcomeCard with a title and a short message.
2. The app starts with a Generate a welcome card button.
3. Selecting the button sends the prompt in the published example. The button is disabled while the app shows Creating your card...
4. A deterministic local fixture streams model output as AG-UI events through the actual HTTP transport and Hashbrown client runtime.
5. Hashbrown validates the response against the exposed component schema and renders WelcomeCard with the supplied title and message.
6. The completed card reads Welcome to Hashbrown and Let's build something useful with the components you already know.

No provider key is used in the recording. The tutorial's Express server calls the model configured in OPENAI_MODEL; its wording can vary. The model supplies props, while the application supplies the component's markup and behavior. There is no narration.
