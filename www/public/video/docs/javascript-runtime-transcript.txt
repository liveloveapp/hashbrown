Each runtime.run call creates a fresh context. QuickJS evaluation returns a result/error wrapper; the component also catches rejected promises. The configured runtime deadline interrupts synchronous loops. Caller signal callbacks and host operations have cooperative cancellation limits; this is not a memory limit or a way to undo privileged host effects. The exposed host handler runs outside QuickJS and retains host privileges.
