Keep context between turns

This recording uses the Messages and turns text-chat example in www/examples/quickstart/react/src/Conversation.tsx. The same sequence is verified against the Angular example. Presentation styles and a branded frame are added by the recorder. No narration.

1. The opening frame shows the finished two-turn conversation.
2. The user sends: My name is Sam. Say hello in one sentence.
3. The app shows its loading state while the local fixture streams a scripted reply: Hi Sam, welcome to Hashbrown!
4. The user enters: What is my name?
5. The next request includes the earlier user message and assistant reply. The recorder verifies that the prior assistant message is present in this request.
6. The scripted reply says: Your name is Sam.

The fixture makes this demonstration deterministic; a real model's wording may vary. The conversation remains in the current chat instance. This video does not demonstrate saving messages or restoring them after a refresh. See Message history for persistence and restoration.
