Refresh. Restore. Continue.

Recorded from www/examples/quickstart/react/src/SavedConversations.tsx, with the same interactions verified in Angular. The real client runtime consumes scripted AG-UI responses. Presentation styles and a branded frame are added by the recorder. No narration.

1. The opening frame shows the completed Personal conversation.
2. Send: My name is Sam. Say hello in one sentence. The fixture streams: Hi Sam, welcome to Hashbrown!
3. Save the completed exchange to this browser, then refresh. The saved messages return without a new agent run.
4. Select Work, send Lee’s name, and receive a separate greeting.
5. Select Personal again. Sam’s exchange returns; Lee’s exchange stays in Work.
6. Ask: What is my name? The request contains the restored assistant message and the Personal thread ID. The fixture answers: Your name is Sam.

This example stores only completed user and assistant text in versioned browser storage. It does not restore generated UI, tools, activities, shared state, provider metadata, or a pending interrupt checkpoint. Thread IDs identify the two example conversations; the application loads and saves their text.
